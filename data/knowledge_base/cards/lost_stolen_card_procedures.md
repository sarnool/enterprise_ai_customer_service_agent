## Card Blocking Process

### Step 1: Instant Block

**Via Mobile App (Recommended - Instant):**
1. Login to mobile banking app
2. Navigate to "Card Services"
3. Select "Block Card"
4. Choose card and confirm
5. Card blocked immediately
6. Confirmation SMS sent

**Via Customer Care (2-3 minutes):**
1. Call helpline and verify identity
2. Confirm card details
3. Request immediate block
4. Note complaint reference number
5. Receive confirmation SMS/email

**Impact of Blocking:**
- All transactions declined immediately
- Card cannot be unblocked (replacement required)
- Auto-debit/standing instructions stopped
- Block is irreversible

---

### Step 2: File Complaint

**Complaint Registration:**
- Complaint ID generated automatically
- Reference number sent via SMS and email
- Valid for 90 days
- Required for investigation and replacement

**Police Report (FIR):**
- Recommended for high-value fraud cases
- Mandatory if fraudulent transactions > ₹50,000
- Submit FIR copy to bank for investigation
- Helps in insurance claim (if applicable)

## Handling Fraudulent Transactions

### If Transactions Occurred Before Blocking

**Check Transaction History:**
- Review last 30 days of transactions via app/internet banking
- Identify unauthorized transactions
- Note details: date, amount, merchant name

**Report Unauthorized Transactions:**
1. Call customer care with transaction details
2. File dispute within 3 days of card loss
3. Submit written complaint (email or branch)
4. Provide FIR copy if filed

**Timeline for Reporting:**
- **Within 24 hours:** Zero liability
- **24-72 hours (3 days):** Limited liability (max ₹10,000)
- **After 3 days:** As per investigation outcome

---

### Dispute Investigation Process

**Stage 1: Initial Review (7 days)**
- Transaction details verified
- Merchant contacted
- CCTV/transaction logs reviewed

**Stage 2: Investigation (15-30 days)**
- Detailed forensic analysis
- Card usage pattern matching
- Geographic location verification

**Stage 3: Resolution (30-45 days)**
- Decision communicated to customer
- Refund processed if fraud confirmed
- Permanent record updated

**Provisional Credit:**
- Temporary credit issued during investigation (for claims₹25,000 and below)
- Reversed if claim found invalid

## Preventing Future Loss

### Physical Card Security

**Best Practices:**
- Keep card in secure wallet/holder
- Don't carry all cards together
- Use card protector sleeves (RFID blocking)
- Note card details separately (stored securely, not with card)
- Take photo of card (front only, never share)

**Travel Tips:**
- Carry backup card
- Store cards in different bags
- Use hotel safe for extra cards
- Keep emergency contact numbers handy

---

### Digital Security Measures

**Enable Alerts:**
- SMS alert for every transaction
- Email notification for online transactions
- Push notifications on mobile app
- Low balance alerts

**Set Transaction Limits:**
- Daily ATM withdrawal limit
- Daily POS transaction limit
- Online transaction limit
- Per-transaction limit

**Use Card Controls:**
- Turn card OFF when not in use
- Disable international transactions
- Block specific merchant categories
- Set geographic restrictions

## FAQs - Lost/Stolen Cards

**Q1: Can I unblock my card if I find it later?**  
A: No. Once blocked, card must be replaced. Block is permanent and irreversible.

**Q2: Will my recurring payments (EMIs, subscriptions) continue?**  
A: No. All standing instructions are stopped. You must update new card details with service providers.

**Q3: What happens to my reward points?**  
A: Reward points are linked to your account, not the card. They remain intact and transfer to new card.

**Q4: Can I get a replacement card with the same number?**  
A: No. New card will have a new number for security reasons.

**Q5: Do I need to inform all merchants where I've saved my card?**  
A: Yes. Update new card details for subscriptions, EMI mandates, and saved payment methods.

**Q6: Will I be liable for transactions after I report the loss?**  
A: No. Zero liability for transactions occurring after you report the loss.

**Q7: Can someone use my card without PIN?**  
A: Yes, for contactless payments up to ₹5,000 and some online transactions (if they have CVV). Report immediately to minimize risk.

**Q 8: How do I know if my replacement card has been dispatched?**  
A: You'll receive SMS/email with courier tracking details once card is dispatched.

**Q9: Can I collect my replacement card from the branch?**  
A: Yes, but only at the home branch. Request branch pickup during replacement request.

**Q10: What if I'm traveling abroad when my card is lost?**  
A: Call international helpline immediately. Emergency card can be arranged in select countries. Alternatively, use mobile wallet or backup card.

## Auto-Debit and Standing Instructions

### Impact of Card Replacement

**Affected Services:**
- EMI payments linked to card
- Utility bill auto-pay
- Subscription services (Netflix, Amazon, etc.)
- Insurance premium auto-debit
- SIP payments

**Action Required:**
1. List all services with saved card
2. Update new card details with each service provider
3. Update Standing Instruction (SI) mandates at bank
4. Test with small transaction to confirm

**Bank's Assistance:**
- List of registered auto-debits provided on request
- Manual update support for bank's own services (loan EMIs, etc.)
- Reminder sent for pending SI updates
